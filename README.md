# AI Health Assistant 🩺🤖

An AI-powered healthcare web application developed using Python, Flask, and Machine Learning. This system predicts possible diseases based on user symptoms through a simple and interactive web interface.

## 🚀 Features

* Symptom-based disease prediction
* Machine Learning integration
* Interactive and modern UI
* Flask web application
* Real-time prediction results

## 🛠️ Technologies Used

* Python
* Flask
* HTML/CSS
* Scikit-learn
* Pandas
* NumPy

## 📌 How It Works

1. User selects symptoms
2. Machine Learning model analyzes the input
3. System predicts the possible disease
4. Result is displayed instantly

## ▶️ Run the Project

Install required libraries:

```bash
pip install flask scikit-learn pandas numpy
```

Run the application:

```bash
python app.py
```

Open in browser:

```bash
http://127.0.0.1:5000
```
